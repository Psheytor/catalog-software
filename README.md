# catalog-software
Разработанный веб-сайт представляет собой информационную систему для учета установленного ПО, контроля лицензионной чистоты и управления лицензиями. Система обеспечивает ведение реестра ПО, привязку к конкретным ПК и автоматическое напоминание об истечении срока действия лицензий.
